Chapter 1

Setup & Hello World

Install your tools, create your first project, and see it run on your phone. No coding experience required.

What You'll Learn

Welcome to your very first coding lesson! Before we write any code, let's understand what we're about to do.

What is programming?

Programming is giving instructions to a computer. Just like a recipe tells you how to cook a meal, code tells your phone or computer what to do. When you write code, you're creating a set of step-by-step instructions that a machine can follow.

What is React Native?

React Native is a tool that lets you write code once and run it on both iPhone and Android. Instead of building two separate apps, you write one set of code and React Native translates it for each phone. It's like writing a letter that works in any language.

What is Expo?

Expo is a set of tools built on top of React Native that makes everything easier. It handles all the complicated setup so you can focus on writing your app. Think of Expo as the easy mode for building mobile apps.

What you'll build

By the end of all 10 chapters, you'll have a fully working app called LinkSpice on your phone. You'll be able to save links, organize them into spaces, switch between dark and light themes, and more. But right now, we're just going to get a simple "Hello World" message to show up on your phone. Let's go!

⚡ Why this matters

You can't build a house without tools. This chapter sets up the exact tools you need: a code editor to write code, a phone app to preview it, and a project to work in. Every chapter after this builds on what you set up right now.

Step 1 — Install Node.js

Node.js is the engine that runs your code on your computer. It lets you execute JavaScript (the programming language we'll use) outside of a web browser. You need it installed before anything else will work.

1

Go to nodejs.org

Open your web browser and visit https://nodejs.org. You'll see two big download buttons.

2

Download the LTS version

Click the button that says LTS (Long Term Support). This is the stable, recommended version. The other version (Current) might have bugs since it's brand new. Always pick LTS when you're starting out.

3

Run the installer

Once the download finishes, open the file. A setup wizard will appear. You can safely click Next through every screen. You don't need to change any settings. Just keep clicking Next, then Install, then Finish.

4

Verify it worked

Open your computer's terminal (Terminal on Mac, Command Prompt or PowerShell on Windows) and type this command:

Terminal 
node --version

If you see a version number like v20.11.0, Node.js is installed correctly. If you see an error like "node is not recognized", close your terminal and open a new one. If it still doesn't work, try restarting your computer.

✔ Tip

The version number doesn't need to match exactly. Any version starting with v18 or higher is fine. Don't worry about which version you have.

Step 2 — Install VS Code

VS Code (Visual Studio Code) is a code editor. This is where you'll type all your code. It's free, fast, and the most popular editor in the world. It has features like auto-complete (it guesses what you're about to type), syntax highlighting (colors your code to make it easier to read), and extensions (extra tools you can add).

1

Go to code.visualstudio.com

Open your browser and visit https://code.visualstudio.com. Click the big download button for your operating system.

2

Install and open

Run the installer. Again, the defaults are fine. Just click through the installation. When it's done, open VS Code.

3

Install the extension

VS Code has extensions that add features. We want one that gives us handy code shortcuts for React Native.

Press Ctrl+Shift+X (or Cmd+Shift+X on Mac) to open the Extensions panel. Search for "ES7+ React/Redux/React-Native snippets" by dsznajder. Click Install.

This extension gives you shortcuts like typing rnfs and pressing Tab to automatically create a React Native component file. You don't need to use this now, but it'll be very helpful later.

✔ Tip

When you're ready to open your project, just open VS Code, go to File → Open Folder, and select your project folder. We'll do this in a later step.

Step 3 — Install Expo Go on Your Phone

Expo Go is a free app that lets you preview your code on a real phone. Instead of waiting for a long build process, you write code, save it, and instantly see the result on your phone. It's like a live preview button, but on your actual device.

1

iPhone users

Open the App Store, search for "Expo Go", and tap Install. It's made by Expo and it's completely free.

2

Android users

Open the Play Store, search for "Expo Go", and tap Install. Same app, same free, same easy.

3

Don't open it yet

Just install it and leave it. We'll use it in Step 5 after we create our project. There's nothing to see in Expo Go until you have a project running.

⚠ Important

Your phone and computer must be connected to the same WiFi network for Expo Go to work. This is how they talk to each other. If you're at home, this is already the case. If you're on a university or work network, some block device-to-device communication. If preview doesn't work later, try using your phone's mobile hotspot instead.

Step 4 — Create Your First Project

This is where the magic starts. We're going to create a brand new project folder with everything set up and ready to go.

1

Open your terminal

On Windows, open PowerShell or Command Prompt. On Mac, open Terminal. You can find these by searching in your start menu or spotlight.

2

Navigate to your Desktop

Let's create our project on the Desktop so it's easy to find. Type this command and press Enter:

Terminal 
cd ~/Desktop

This command means "change directory to my Desktop." cd stands for "change directory" and ~ means "my home folder." On Windows Command Prompt, you might need to type cd %USERPROFILE%\Desktop instead.

3

Create the project

Run these three commands one at a time. Copy each line, paste it into your terminal, and press Enter:

Terminal 
npx create-expo-app@latest LinkSpice
cd LinkSpice
npm start

Let's break down what each command does:

  • npx create-expo-app@latest LinkSpice — This downloads and runs the Expo project creator. It builds a brand new project folder called "LinkSpice" with all the starter files you need. The @latest part means it always gets the newest version.
  • cd LinkSpice — This moves you inside the LinkSpice folder. All your future commands should be run from inside this folder.
  • npm start — This starts the development server. It watches your code files and serves your app so it can be previewed on your phone. A big QR code should appear in your terminal.
⚡ Why this matters

The npm start command is one you'll use constantly. Whenever you want to preview your app, open a terminal, go to your LinkSpice folder, and run npm start. It's like turning on the power to your workshop.

Step 5 — Run on Your Phone

Now that your project is running, let's see it on your actual phone. This is the exciting part!

1

Look at your terminal

You should see a QR code and a URL that looks something like exp://192.168.1.5:8081. This is your app's address on your local network.

2

Scan the QR code

Open the Expo Go app on your phone. If you're on iPhone, use your Camera app to scan the QR code. If you're on Android, use the built-in scanner in Expo Go. The app will load automatically.

3

You should see the welcome screen

After a few seconds of loading, your phone should show a screen that says "Welcome to Expo" with the Expo logo. This means everything is working!

❌ If it doesn't work

Make sure your phone and computer are on the same WiFi. If it still fails, try turning off VPN on either device. If you're still stuck, close the terminal, run npm start again, and try once more.

Understanding the Code

Let's look at the actual code that makes your app work. In VS Code, open your LinkSpice folder (File → Open Folder) and find the file called App.js. This is the main file of your app. Open it and you'll see something like this:

App.js 
import { Text, View, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text>Hello LinkSpice!</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
});

Let's understand every line:

  • import { Text, View, StyleSheet } from 'react-native'; — This brings in tools we need. Text lets us display words on screen. View is like a container (like a box). StyleSheet lets us add styles like colors and sizes.
  • export default function App() { } — This defines our main component. A component is a piece of the app. Every React Native app is made of components. The App component is the root — it's the first thing that runs.
  • <View style={styles.container}> — This creates a View (a box) that fills the whole screen. The style part applies our container styles.
  • <Text>Hello LinkSpice!</Text> — This displays the text "Hello LinkSpice!" on the screen. This is what you see on your phone right now.
  • const styles = StyleSheet.create({ }); — This defines the styles. flex: 1 means "fill all available space." alignItems: 'center' centers horizontally. justifyContent: 'center' centers vertically.
⚡ Why this matters

Every screen in your app is made of components like this one. Components are reusable building blocks. Later, you'll create components for buttons, cards, input fields, and entire screens. This simple App component is the foundation of everything you'll build.

Step 6 — Change the Text

The best way to learn is by doing. Let's make a change and watch it happen on your phone in real time.

1

Open App.js in VS Code

In VS Code, open your LinkSpice folder if you haven't already. Find App.js in the file list on the left and click to open it.

2

Change the text

Find the line that says <Text>Hello LinkSpice!</Text>. Change it to your name:

App.js 
import { Text, View, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text>Hello, my name is Abdul!</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
3

Save the file

Press Ctrl+S (or Cmd+S on Mac) to save. Look at your phone — it should automatically update with your new text! No need to restart anything. This is called hot reloading, and it makes development super fast.

✔ Tip

Hot reloading is one of the best things about Expo. Every time you save a file, your phone updates instantly. You can experiment and see results immediately. Never be afraid to try things — you can always undo changes.

✔ What You Should See

After completing all the steps above, your phone should show:

  • A white (or dark) screen with your name displayed in the center
  • If you changed the text and saved, the new text appears instantly
  • The terminal is still running (don't close it while you're working)

If you see your name on the screen, congratulations — you just wrote and ran your first mobile app!
