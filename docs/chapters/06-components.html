Components

Build reusable UI pieces with React Native components, props, and styles. See the real LinkSpice components in action.

What You'll Learn

In this chapter, you'll understand:

  • What components are — reusable building blocks that make up every screen
  • How props work — passing data into components so they display the right information
  • How StyleSheet works — giving your components colors, sizes, and layout
  • Real LinkSpice components — reading Button, SpaceCard, Screen, and LinkPreviewCard
  • Building your own component — creating a UserProfile component from scratch

What is a Component?

A component is a function that returns JSX — the special markup that React Native turns into what you see on screen. Think of each component like a Lego brick: small, self-contained, and reusable. You snap them together to build bigger things like screens and entire apps.

Here is the simplest possible component:

SimpleComponent.tsx 
export function Greeting() {
  return (
    <View>
      <Text>Hello, world!</Text>
    </View>
  );
}

That's it. A function with a name, returning some JSX. You can then use <Greeting /> anywhere in your app — just like using a built-in element.

Why components matter

Without components, you'd write the same button code on every screen. With components, you write it once and reuse it everywhere. If you ever want to change the button, you change it in one place and every screen updates automatically.

Props — Passing Data Into Components

Components become powerful when they accept props (short for "properties"). Props are inputs you pass into a component, just like arguments to a function. They let the same component display different data each time you use it.

Here's a component with props:

UserBadge.tsx 
interface UserBadgeProps {
  name: string;
  age: number;
}

export function UserBadge({ name, age }: UserBadgeProps) {
  return (
    <View>
      <Text>{name} is {age} years old</Text>
    </View>
  );
}

Now you can use it with different data:

Usage 
<UserBadge name="Alice" age={25} />
<UserBadge name="Bob" age={30} />

Each use passes different values. The component is the same — the props change.

Props are like function arguments

If you know what a function parameter is, you already know props. function greet(name) takes name as a parameter. A component takes props the same way — they're values you pass in when you use the component.

StyleSheet — How to Style Components

React Native doesn't use CSS files like websites. Instead, you define styles in JavaScript using StyleSheet.create(). It works like CSS but with JavaScript syntax — property names are camelCase instead of kebab-case.

StyleSheet Example 
const styles = StyleSheet.create({
  container: {
    flex: 1,              // fill all available space
    backgroundColor: '#0a0a0c',  // dark background
    padding: 16,          // space inside the edges
  },
  title: {
    fontSize: 18,         // text size
    fontWeight: '600',    // bold-ish
    color: '#e4e4e7',    // light text
  },
});

Here are the most common style properties you'll see:

  • flex: 1 — make the element fill all available space
  • backgroundColor — the background color
  • padding / margin — space inside / outside the element
  • borderRadius — round the corners
  • fontSize — text size
  • color — text color
  • fontWeight — how bold the text is
  • flexDirection: 'row' — lay children out horizontally instead of vertically
  • alignItems / justifyContent — alignment controls

The Button Component

The LinkSpice Button is a great first real component to study. It accepts props for the label text, a press handler, a visual variant, size, icons, and more. Here's the actual code from the app:

src/components/Button.tsx 
import { Pressable, StyleSheet, Text } from 'react-native';
import { Ionicons } from '@expo/vector-icons';
import { useTheme } from '../theme/ThemeContext';
import { radius, spacing, type } from '../theme/tokens';

export type ButtonVariant = 'primary' | 'secondary' | 'danger' | 'ghost';

interface ButtonProps {
  label?: string;
  onPress?: () => void;
  variant?: ButtonVariant;
  disabled?: boolean;
  icon?: keyof typeof Ionicons.glyphMap;
  iconSize?: number;
  size?: 'sm' | 'md' | 'lg';
  fullWidth?: boolean;
}

export function Button({
  label,
  onPress,
  variant = 'primary',
  disabled = false,
  icon,
  iconSize = 18,
  size = 'md',
  fullWidth = false,
}: ButtonProps) {
  const { palette } = useTheme();

  const backgrounds: Record<ButtonVariant, string> = {
    primary: palette.accent,
    secondary: palette.surfaceRaised,
    danger: palette.danger,
    ghost: 'transparent',
  };

  const foreground: Record<ButtonVariant, string> = {
    primary: '#FFFFFF',
    secondary: palette.textPrimary,
    danger: '#FFFFFF',
    ghost: palette.textSecondary,
  };

  const height = size === 'sm' ? 36 : size === 'md' ? 44 : 52;
  const font = size === 'lg' ? type.body : type.label;

  return (
    <Pressable
      accessibilityRole="button"
      disabled={disabled}
      onPress={onPress}
      style={({ pressed }) => [
        styles.base,
        {
          backgroundColor: backgrounds[variant],
          height,
          paddingHorizontal: size === 'sm' ? spacing.md : spacing.lg,
          opacity: disabled ? 0.5 : 1,
          transform: [{ scale: pressed ? 0.98 : 1 }],
          alignSelf: fullWidth ? 'stretch' : 'auto',
        },
        variant === 'ghost' && styles.ghostBorder,
      ]}
    >
      {icon ? (
        <Ionicons name={icon} size={iconSize} color={foreground[variant]} />
      ) : null}
      {label ? (
        <Text style={[font, { color: foreground[variant], fontWeight: '600' }]}>
          {label}
        </Text>
      ) : null}
    </Pressable>
  );
}

const styles = StyleSheet.create({
  base: {
    flexDirection: 'row',
    alignItems: 'center',
    justifyContent: 'center',
    gap: spacing.sm,
    borderRadius: radius.lg,
  },
  ghostBorder: {},
});

Let's break down what's happening:

  • interface ButtonProps — defines what props the button accepts. ? means optional — you don't have to pass every prop.
  • variant = 'primary' — default values. If no variant is passed, it uses 'primary'.
  • useTheme() — gets the current color palette from the app's theme system.
  • Pressable — React Native's touchable element. It supports a pressed state for visual feedback.
  • style={({ pressed }) => [...]} — a function that returns different styles depending on whether the button is pressed.
  • transform: [{ scale: pressed ? 0.98 : 1 }] — shrinks the button slightly when pressed for a tactile feel.
How it's used in the app

Somewhere in LinkSpice, you'll see code like <Button label="Save" onPress={handleSave} />. That's the whole button — the component handles all the styling and behavior internally.

The SpaceCard Component

A SpaceCard shows a "space" (a group of links) on the home screen. It displays a category pill, preview icons of links inside it, the space name, and a link count. Here's the real code:

src/components/SpaceCard.tsx 
import { Pressable, StyleSheet, Text, View } from 'react-native';
import { useTheme } from '../theme/ThemeContext';
import { type } from '../theme/tokens';
import { formatCount } from '../lib/format';
import { categoryAccent, categoryFor } from './spaceCategories';
import { SpaceCategoryPill } from './SpaceCategoryPill';
import { SpacePreviewRow } from './SpacePreviewRow';
import { SpaceMoreButton } from './SpaceMoreButton';
import { useResponsive } from '../hooks/useResponsive';
import type { Space } from '../types';
import type { LinkPreview } from '../repositories/links';

interface SpaceCardProps {
  space: Space;
  count: number;
  previews: LinkPreview[];
  onPress?: () => void;
  onMenu?: () => void;
  onAddLink?: () => void;
}

export function SpaceCard({
  space,
  count,
  previews,
  onPress,
  onMenu,
  onAddLink,
}: SpaceCardProps) {
  const { palette } = useTheme();
  const r = useResponsive();
  const category = categoryFor(space.id);
  const accent = category ? categoryAccent(category, space.color) : space.color;

  const cardHeight = r.width < 360 ? 170 : r.width < 412 ? 185 : 200;
  const pad = r.width < 360 ? 14 : r.width < 412 ? 16 : 18;

  return (
    <Pressable
      accessibilityRole="button"
      onPress={onPress}
      style={({ pressed }) => [
        styles.card,
        {
          height: cardHeight,
          borderRadius: r.width < 360 ? 16 : 18,
          padding: pad,
          backgroundColor: palette.surface,
          transform: [{ scale: pressed ? 0.98 : 1 }],
        },
      ]}
    >
      {/* Top row: category pill left, three-dot menu right */}
      <View style={styles.topRow}>
        {category ? (
          <SpaceCategoryPill
            label={category}
            accent={accent}
            height={r.width < 360 ? 30 : 34}
            dotSize={r.width < 360 ? 5 : 6}
            fontSize={11}
          />
        ) : (
          <View style={styles.placeholder} />
        )}
        <SpaceMoreButton onPress={onMenu} iconSize={r.width < 360 ? 14 : 16} />
      </View>

      {/* Preview icons row — overlapping */}
      <View style={styles.previewWrap}>
        <SpacePreviewRow
          previews={previews}
          count={count}
          accent={accent}
          iconName={space.icon}
          iconColor={accent}
          tileSize={r.width < 360 ? 32 : 36}
          overlap={6}
        />
      </View>

      {/* Title and link count */}
      <View style={styles.info}>
        <Text style={[styles.title, { color: palette.textPrimary }]} numberOfLines={1}>
          {space.name}
        </Text>
        <Text style={[styles.count, { color: palette.textSecondary }]}>
          {formatCount(count)} link{count === 1 ? '' : 's'}
        </Text>
      </View>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  card: {
    flex: 1,
    overflow: 'hidden',
    justifyContent: 'space-between',
  },
  topRow: {
    flexDirection: 'row',
    alignItems: 'center',
    justifyContent: 'space-between',
  },
  placeholder: {
    width: 1,
    height: 30,
  },
  previewWrap: {},
  info: {
    gap: 2,
  },
  title: {
    fontSize: 16,
    fontWeight: '600',
    letterSpacing: -0.3,
  },
  count: {
    fontSize: 13,
    fontWeight: '400',
  },
});

Key things to notice:

  • Props define the data — space, count, previews are all data passed in from the parent screen.
  • Responsive sizing — useResponsive() returns the screen width, so the card adjusts its height and padding for different phone sizes.
  • Composed from smaller components — SpaceCategoryPill, SpacePreviewRow, and SpaceMoreButton are all separate components used inside this one.
  • Conditional rendering — {category ? (...) : (...)} shows the pill if a category exists, or a placeholder if not.

The LinkPreviewCard Component

This component shows a preview of a single link — with a thumbnail image (or brand logo, or fallback image), the title, and the domain. Here's the actual code:

src/components/LinkPreviewCard.tsx 
import { Pressable, StyleSheet, Text, View, Image } from 'react-native';
import { Ionicons } from '@expo/vector-icons';
import { useTheme } from '../theme/ThemeContext';
import { brandFor } from '../lib/brand';
import { getDomain } from '../lib/url';
import { useResponsive } from '../hooks/useResponsive';
import type { Link } from '../types';

const FALLBACK_IMAGES = [
  require('../../assets/images/sunflower-robot.png'),
  require('../../assets/images/fantom-logo.png'),
];

interface LinkPreviewCardProps {
  link: Link;
  onPress?: () => void;
}

export function LinkPreviewCard({ link, onPress }: LinkPreviewCardProps) {
  const { palette } = useTheme();
  const r = useResponsive();
  const brand = brandFor(link.url);
  const domain = link.domain || getDomain(link.url);
  const hasImage = link.thumbnail?.startsWith('http') || link.favicon?.startsWith('http');
  const fallbackImage = FALLBACK_IMAGES[Math.abs(link.id.charCodeAt(0)) % FALLBACK_IMAGES.length];

  const cardH = r.width < 360 ? 120 : r.width < 412 ? 130 : 140;
  const imgSize = cardH - 24;
  const pad = r.width < 360 ? 12 : 14;

  return (
    <Pressable
      accessibilityRole="button"
      onPress={onPress}
      style={({ pressed }) => [
        styles.card,
        {
          height: cardH,
          borderRadius: r.width < 360 ? 14 : 16,
          padding: pad,
          backgroundColor: palette.surface,
          transform: [{ scale: pressed ? 0.98 : 1 }],
        },
      ]}
    >
      <View style={[styles.imageWrap, { width: imgSize, height: imgSize, borderRadius: r.width < 360 ? 10 : 12, backgroundColor: brand?.bg ?? palette.surfaceRaised }]}>
        {hasImage ? (
          <Image
            source={{ uri: (link.thumbnail || link.favicon) ?? undefined }}
            style={[styles.image, { borderRadius: r.width < 360 ? 10 : 12 }]}
          />
        ) : brand ? (
          <Text style={[styles.brandLabel, { color: brand.fg, fontSize: Math.round(imgSize * 0.5) }]}>
            {brand.label}
          </Text>
        ) : (
          <Image source={fallbackImage} style={[styles.image, { borderRadius: r.width < 360 ? 10 : 12 }]} />
        )}
      </View>

      <View style={styles.info}>
        <Text style={[styles.title, { color: palette.textPrimary }]} numberOfLines={2}>
          {link.title || domain}
        </Text>
        <Text style={[styles.domain, { color: palette.textSecondary }]} numberOfLines={1}>
          {domain}
        </Text>
      </View>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  card: {
    flexDirection: 'row',
    alignItems: 'center',
    gap: 12,
  },
  imageWrap: {
    alignItems: 'center',
    justifyContent: 'center',
    overflow: 'hidden',
  },
  image: {
    width: '100%',
    height: '100%',
  },
  brandLabel: {
    fontWeight: '700',
  },
  info: {
    flex: 1,
    gap: 4,
  },
  title: {
    fontSize: 15,
    fontWeight: '600',
    letterSpacing: -0.2,
  },
  domain: {
    fontSize: 13,
    fontWeight: '400',
  },
});

Notice how this component handles three different image scenarios:

  • Has a thumbnail URL — shows the actual image from the web
  • Has a known brand — shows the brand's label and color (like a GitHub or YouTube logo)
  • Neither — falls back to a local placeholder image
Why this pattern matters

The ?? and || operators are used for fallbacks. link.domain || getDomain(link.url) means "use the domain if it exists, otherwise extract it from the URL." This makes the component resilient — it works even with incomplete data.

The Screen Component

The Screen component is a simple wrapper that every screen in LinkSpice uses. It adds safe area padding (so content doesn't go behind the notch or status bar) and sets the background color from the theme.

src/components/Screen.tsx 
import type { ReactNode } from 'react';
import { StyleSheet, View, type StyleProp, type ViewStyle } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import { useTheme } from '../theme/ThemeContext';

interface ScreenProps {
  children: ReactNode;
  style?: StyleProp<ViewStyle>;
}

export function Screen({ children, style }: ScreenProps) {
  const { palette } = useTheme();
  return (
    <SafeAreaView
      edges={['top', 'left', 'right', 'bottom']}
      style={[styles.screen, { backgroundColor: palette.background }, style]}
    >
      {children}
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  screen: {
    flex: 1,
  },
});

Key things to notice:

  • children: ReactNode — this prop accepts any JSX. It's how wrapper components work — you put content inside the component and it wraps around it.
  • SafeAreaView — a React Native component that adds padding so content stays away from notches, rounded corners, and the status bar.
  • edges={['top', 'left', 'right', 'bottom']} — tells SafeAreaView to add safe padding on all four sides.
  • flex: 1 — makes the screen fill the entire phone display.

Every screen in LinkSpice wraps its content like this:

Usage in a screen 
export default function HomeScreen() {
  return (
    <Screen>
      <Text>Welcome home!</Text>
    </Screen>
  );
}

Building It — Your Own Component

Now let's build a UserProfile component step by step. This component will show a user's name, their bio, and a follow button. We'll use everything we've learned.

1

Create the file

Inside src/components/, create a new file called UserProfile.tsx.

2

Define the props

First, figure out what data this component needs. It needs a user's name, their bio, and a callback for when the follow button is pressed.

src/components/UserProfile.tsx 
import { View, Text, StyleSheet } from 'react-native';
import { useTheme } from '../theme/ThemeContext';
import { Button } from './Button';

interface UserProfileProps {
  name: string;
  bio: string;
  onFollow?: () => void;
}

export function UserProfile({ name, bio, onFollow }: UserProfileProps) {
  const { palette } = useTheme();

  return (
    <View style={[styles.card, { backgroundColor: palette.surface }]}>
      <View style={styles.avatar}>
        <Text style={[styles.initial, { color: palette.accent }]}>
          {name.charAt(0).toUpperCase()}
        </Text>
      </View>

      <View style={styles.info}>
        <Text style={[styles.name, { color: palette.textPrimary }]}>{name}</Text>
        <Text style={[styles.bio, { color: palette.textSecondary }]}>{bio}</Text>
      </View>

      <Button
        label="Follow"
        onPress={onFollow}
        variant="secondary"
        size="sm"
      />
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    flexDirection: 'row',
    alignItems: 'center',
    padding: 16,
    borderRadius: 14,
    gap: 12,
  },
  avatar: {
    width: 44,
    height: 44,
    borderRadius: 22,
    backgroundColor: '#1a1a1e',
    alignItems: 'center',
    justifyContent: 'center',
  },
  initial: {
    fontSize: 18,
    fontWeight: '700',
  },
  info: {
    flex: 1,
    gap: 2,
  },
  name: {
    fontSize: 15,
    fontWeight: '600',
  },
  bio: {
    fontSize: 13,
  },
});
3

Use it in a screen

Import and use it just like any other component:

Usage 
import { UserProfile } from '../src/components/UserProfile';

export default function ProfileScreen() {
  return (
    <Screen>
      <UserProfile
        name="Alice"
        bio="Building cool things with LinkSpice"
        onFollow={() => console.log('Followed!')}
      />
    </Screen>
  );
}
Notice the pattern

We reused the Button component we studied earlier instead of building a new button from scratch. This is the whole point of components — compose small pieces into bigger ones. The UserProfile is made of View, Text, and Button.
