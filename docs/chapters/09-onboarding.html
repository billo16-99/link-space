What is Onboarding?

Onboarding is the first thing a new user sees when they open your app. It introduces the app, explains what it does, and guides the user through setup.

Link Space has 5 onboarding screens:

  1. Splash — Logo animation (1.5 seconds)
  2. Welcome — Floating cards + "Get Started" button
  3. Choose Spaces — Pick suggested categories
  4. Saving Demo — Animated visualization of how saving works
  5. Ready — "You're all set!" → go to home screen
💡 Why this matters

Without onboarding, a new user opens the app and sees an empty screen. They don't know what to do. Onboarding teaches them in 30-60 seconds.

The Splash Screen

The splash screen shows the Link Space logo with a scale+fade animation, then automatically navigates to the welcome screen after 1.5 seconds.

app/onboarding/splash.tsx 
import { useEffect, useRef } from 'react';
import { Animated, StyleSheet, View } from 'react-native';
import { router } from 'expo-router';
import { useTheme } from '../../src/theme/ThemeContext';

export default function Splash() {
  const { palette } = useTheme();
  const scale = useRef(new Animated.Value(0.8)).current;
  const opacity = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    // Animate: scale from 0.8 to 1, fade in
    Animated.parallel([
      Animated.spring(scale, {
        toValue: 1,
        useNativeDriver: true,
        damping: 12,
        stiffness: 100,
      }),
      Animated.timing(opacity, {
        toValue: 1,
        duration: 400,
        useNativeDriver: true,
      }),
    ]).start();

    // After 1.5 seconds, go to Welcome screen
    const timer = setTimeout(() => {
      router.replace('/onboarding/welcome');
    }, 1500);

    return () => clearTimeout(timer);
  }, []);

  return (
    <View style={[styles.container, { backgroundColor: palette.background }]}>
      <Animated.View style={[styles.logoWrap, {
        transform: [{ scale }],
        opacity
      }]}>
        <View style={[styles.logoIcon, { backgroundColor: palette.accent }]}>
          <View style={styles.logoInner}>
            <View style={[styles.logoDot, { backgroundColor: '#FFFFFF' }]} />
          </View>
        </View>
        <Animated.Text style={[styles.wordmark, {
          color: palette.textPrimary, opacity
        }]}>
          Link Space
        </Animated.Text>
      </Animated.View>
    </View>
  );
}
💡 Key concepts

useRef(new Animated.Value(0)) creates an animation value that persists across re-renders. Animated.parallel runs multiple animations at the same time. router.replace navigates without a back button (can't go back to splash).

The Welcome Screen

This is the main onboarding screen. It shows floating link cards that animate in, a headline, and two buttons: "Get Started" and "I already have an account".

app/onboarding/welcome.tsx (simplified) 
function FloatingCard({ delay, x, y, color, icon }) {
  const floatY = useRef(new Animated.Value(0)).current;
  const opacity = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    // Fade in after delay, then float up and down
    Animated.sequence([
      Animated.delay(delay),
      Animated.parallel([
        Animated.timing(opacity, { toValue: 1, duration: 500 }),
        Animated.spring(floatY, { toValue: -8, damping: 12 }),
      ]),
    ]).start();

    // Continuous floating loop
    Animated.loop(
      Animated.sequence([
        Animated.timing(floatY, { toValue: -12, duration: 2000 }),
        Animated.timing(floatY, { toValue: -4, duration: 2000 }),
      ])
    ).start();
  }, []);

  return (
    <Animated.View style={{ left: x, top: y, opacity,
      transform: [{ translateY: floatY }] }}>
      <View style={{ backgroundColor: color, ... }}>
        <Ionicons name={icon} size={16} color="#FFFFFF" />
      </View>
    </Animated.View>
  );
}

export default function Welcome() {
  // ... render 4 FloatingCards with different delays and positions
  // ... headline: "Your links, finally in their place."
  // ... "Get Started" button → /onboarding/choose-spaces
  // ... "I already have an account" → mark complete, go to /
}
✅ How the animation works

Each card has a different delay (200ms, 400ms, 600ms, 800ms) so they appear one after another. The Animated.loop makes them float up and down forever.

Persisting Onboarding State

We need to remember if the user has already seen onboarding. If they close the app and reopen it, they should go straight to the home screen.

src/lib/settings.ts 
import Storage from 'expo-sqlite/kv-store';

const KEYS = {
  onboardingCompleted: 'settings_onboarding_completed',
} as const;

export function getOnboardingCompleted(): boolean {
  try {
    const raw = Storage.getItemSync(KEYS.onboardingCompleted);
    if (raw === 'true') return true;
    if (raw === 'false') return false;
  } catch {}
  return false;  // Default: not completed
}

export function setOnboardingCompleted(v: boolean) {
  try {
    Storage.setItemSync(KEYS.onboardingCompleted, String(v));
  } catch {}
}

Then in _layout.tsx, we check this value on startup:

app/_layout.tsx (OnboardingGate) 
function OnboardingGate() {
  const [checked, setChecked] = useState(false);

  useEffect(() => {
    const completed = getOnboardingCompleted();
    if (!completed) {
      router.replace('/onboarding/splash');
    }
    setChecked(true);
  }, []);

  if (!checked) return null;  // Show nothing while checking

  return <Stack ... />;
}
💡 Why check on startup?

The app needs to decide immediately: show onboarding or show home? We check the stored value, redirect if needed, then render the app. The if (!checked) return null prevents a flash of the wrong screen.

The Search Screen

Search lets users find links by title, URL, or tags. It uses a text input and filters results in real time.

app/search.tsx (key part) 
import { useSearch } from '../src/hooks/useSpaces';

export default function SearchScreen() {
  const [query, setQuery] = useState('');
  const [filter, setFilter] = useState('all');
  const results = useSearch(query, filter);

  return (
    <View>
      <TextInput
        placeholder="Search links..."
        value={query}
        onChangeText={setQuery}
      />
      {results.links.map(link => (
        <LinkPreviewCard key={link.id} link={link} />
      ))}
    </View>
  );
}
✅ How search works

The useSearch hook calls searchDb() from the repositories, which runs a SQL query: SELECT * FROM links WHERE title LIKE '%query%'. It re-runs every time the query changes.

The Settings Screen

Settings lets users configure defaults and preferences. All settings are stored using the same key-value store as onboarding.

app/settings.tsx (key part) 
import { getDefaultSpace, setDefaultSpace } from '../src/lib/settings';

export default function SettingsScreen() {
  const [defaultSpace, setDefault] = useState(getDefaultSpace());

  return (
    <View>
      <Text>Default Space</Text>
      <SpacePicker
        value={defaultSpace}
        onChange={(id) => {
          setDefault(id);
          setDefaultSpace(id);
        }}
      />
    </View>
  );
}

The Pinned Links Screen

Pinned links are the user's most important links. They show in the Dynamic Island on the home screen and have their own dedicated screen.

app/pinned.tsx (key part) 
import { usePinnedLinks } from '../src/hooks/useSpaces';
import { LinkPreviewCard } from '../src/components/LinkPreviewCard';

export default function PinnedScreen() {
  const pinnedLinks = usePinnedLinks();

  return (
    <FlatList
      data={pinnedLinks}
      renderItem={({ item }) => (
        <LinkPreviewCard
          link={item}
          onPress={() => router.push(`/link-preview/${item.id}`)}
        />
      )}
    />
  );
}
