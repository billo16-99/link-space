Build & Deploy

The final chapter. Build an APK file anyone can install, push your code to GitHub, and share your app with the world.

What You'll Learn

  • How to build an Android APK file
  • How to push code to GitHub
  • How to create a release with a download link
  • How to share your app with anyone

Step 1: Install EAS CLI

EAS (Expo Application Services) is Expo's build service. It compiles your app in the cloud and gives you a downloadable APK file.

Terminal 
npm install -g eas-cli

Then log in to your Expo account:

Terminal 
eas login
✅ Don't have an account?

Go to expo.dev and create a free account. It takes 30 seconds.

Step 2: Configure the Build

Create an eas.json file in your project root:

eas.json 
{
  "cli": {
    "version": ">= 16.0.0"
  },
  "build": {
    "preview": {
      "android": {
        "buildType": "apk"
      },
      "distribution": "internal"
    },
    "production": {
      "android": {
        "buildType": "app-bundle"
      }
    }
  }
}
💡 APK vs AAB

APK = a file anyone can install directly. AAB = Google Play Store format. We use APK for direct sharing.

Step 3: Initialize EAS Project

Terminal 
eas init --non-interactive --force

This links your project to your Expo account. It creates a project on expo.dev and adds the project ID to your app.json.

Step 4: Build the APK

This is the big moment. Run this command and wait 10-15 minutes:

Terminal 
eas build --platform android --profile preview --non-interactive

What happens:

  1. EAS compresses your project files
  2. Uploads them to Expo's cloud servers
  3. Compiles the app (like baking a cake)
  4. Gives you a download URL when done
⚠️ Takes 10-15 minutes

Don't close the terminal. You'll see a URL when it's done. You can also monitor it at expo.dev under "Builds".

Step 5: Download the APK

When the build finishes, you'll see a URL like:

https://expo.dev/artifacts/eas/CR9-0UYPFY4lmtbNyPYjGYJdgiOa6gRQ2hGwblsrYEI.apk

Download this file. It's your app! Anyone with an Android phone can install it.

To install on your phone:

  1. Transfer the APK to your phone (email, USB, cloud storage)
  2. Open the APK file on your phone
  3. Allow "Install from unknown sources" if prompted
  4. Open LinkSpice!

Step 6: Push to GitHub

GitHub is where developers store their code. It's like Google Drive for code.

Terminal 
# Install GitHub CLI (one time)
winget install GitHub.cli

# Log in
gh auth login

# Create repo and push
git add -A
git commit -m "LinkSpice v1.0.0"
gh repo create link-space --public --source=. --push

Your code is now on GitHub at https://github.com/yourusername/link-space.

Step 7: Create a Release

A GitHub Release lets people download your APK with one click.

Terminal 
gh release create v1.0.0 LinkSpice-v1.0.0.apk \
  --title "LinkSpice v1.0.0" \
  --notes "Save, organize, and find everything you want to come back to."

Now anyone can go to your release page and download the APK:

https://github.com/yourusername/link-space/releases/tag/v1.0.0

Step 8: Enable GitHub Pages (Optional)

If you want a website for your tutorial or docs, enable GitHub Pages:

  1. Go to your repo on GitHub
  2. Settings → Pages
  3. Source: Deploy from a branch
  4. Branch: main, folder: /docs
  5. Save

Your site is live at https://yourusername.github.io/link-space/

✅ What You Should Have

1. An APK file that installs on any Android phone

2. A GitHub repo with all your code

3. A release page where anyone can download the APK

4. (Optional) A tutorial website on GitHub Pages
